# Counter App

This is a simple Counter App made using HTML, CSS and JavaScript.

## Features
- Increase Counter
- Decrease Counter
- Reset Counter
- Simple and clean UI
- Responsive design

## Technologies Used
- HTML
- CSS
- JavaScript

## How It Works
- Click `+` button to increase the count
- Click `-` button to decrease the count
- Click `Reset` button to set counter back to 0

## Project Purpose
This project was created for practicing:
- DOM Manipulation
- JavaScript Functions
- Event Handling
- Basic Frontend Development
